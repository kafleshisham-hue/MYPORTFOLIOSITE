# Contributing

Like my portfolio? Have an idea to make it better? Fork it and send a pull request. I'd appreciate it.

## Quick Steps

1. **Fork** the repo (button in top-right)
2. **Clone** your fork:
   ```bash
   git clone https://github.com/YOUR-USERNAME/portfolio.git
   cd portfolio
   ```
3. **Create a branch** for your changes:
   ```bash
   git checkout -b feature/your-idea
   ```
4. **Make changes** to `index.html`
5. **Test it** in your browser:
   - Click around
   - Check mobile view
   - Open dev tools, make sure no errors
6. **Commit** with a good message:
   ```bash
   git commit -m "Add cool feature"
   ```
7. **Push** to your fork:
   ```bash
   git push origin feature/your-idea
   ```
8. **Create a Pull Request** on the original repo

I'll take a look and merge if it's good.

## Code Style

**HTML:** Keep it clean, 4-space indents, semantic tags

**CSS:** Use the CSS variables at the top, keep it simple

**JavaScript:** camelCase for variables, comments for complex stuff, keep functions small

Basically just write code that makes sense.

## What to Contribute

**Bug fixes:** Something broken? Fix it.

**Features:** Want to add something cool? Go for it.

**Design improvements:** Make it look better.

**Performance:** Make it faster.

**Accessibility:** Make it work for everyone.

**Documentation:** Explain things better.

## What I'll Merge

✅ **Yes:**
- Bug fixes
- Performance stuff
- Better accessibility
- Better docs
- New features that make sense
- Design tweaks

❌ **Nope:**
- Changing my personal info (edit your own fork)
- Adding tracking/analytics without asking
- Breaking changes to how it works
- Spam/nonsense
