# Images Folder

Add your photos here for the portfolio.

## Profile Photo

**File:** `profile.jpg`

Place your professional headshot here. The image will be:
- Displayed in the About section (300x300px circle)
- Automatically cropped to fit the circular frame
- Any format works: `.jpg`, `.png`, `.webp`, etc.

### How to Add Your Photo

1. Take or find a good professional headshot (or casual photo, whatever you prefer)
2. Crop it to a square (or close to square)
3. Save it as `profile.jpg` in this folder
4. Refresh your portfolio in the browser—it'll show up!

### Tips

- **Size:** Aim for at least 400x400px for good quality
- **Format:** JPEG works great, PNG is fine too
- **Style:** Professional headshot is classic, but casual photos work too
- **Background:** Simple backgrounds work best

If the image doesn't load, it'll fall back to showing a user icon. Once you add `profile.jpg`, it'll automatically display.
